# 🛒 Mega Ventas

Aplicación web de e-commerce desarrollada con React y Redux.

## 🚀 Demo

👉 https://Lucas7909.github.io/mega-ventas

## 📦 Funcionalidades

- Listado de productos desde API
- Búsqueda de productos
- Filtro por categorías
- Carrito de compras
- Incremento y decremento de cantidad
- Eliminación de productos
- Vaciar carrito
- Modal de confirmación
- Navegación con React Router
- Página 404

## 🛠️ Tecnologías usadas

- React
- Redux Toolkit
- React Router
- CSS
- Vite
